# RenDoor

## Загальний опис

**RenDoor** - **Платформа збору та аналітики оголошень про оренду житла** з різних відкритих джерел.  
Основний інтерфейс для користувача - **Telegram-бот**, через який можна:

- отримувати нові оголошення відповідно до заданих фільтрів,
- переглядати архів і статистику,
- створювати власні оголошення.

Telegram тут виступає **UI**, але основна цінність проєкту - **збір, нормалізація та фільтрація даних**.

## Мета

- Створити уніфіковану базу оголошень незалежно від джерела.
- Дати користувачу можливість швидко реагувати на нові релевантні пропозиції.
- Відсікати фейки, рієлторів і дублікати.
- Забезпечити доступ до історичних даних і аналітики ринку.

## Джерела оголошень

- **DOM.RIA** — зручні для обробки, нормалізовані.
- **OLX** — складні для парсингу, ненормалізовані.
- **Локальні Telegram-групи** — експериментальний напрям (спочатку для Хмельницького).
- **Користувацькі оголошення** — можливість створювати напряму в боті.

Джерела реалізуються як **плагіни** (єдиний інтерфейс на вхід/вихід).

## Дані оголошення (мінімальний набір)

- Джерело
- Заголовок
- Фото
- Ціна за місяць
- Місто / район
- Адреса + координати
- Кількість кімнат
- Площа
- Поверх
- Опис
- Контакти власника
- Інфо про власника
- Посилання на оригінал

## Сценарії

### MVP

1. Користувач задає фільтри (місто, ціна, кількість кімнат, тощо).
2. Система знаходить відповідні оголошення та відправляє в бот.
3. Користувач отримує push нові оголошення + може зберігати в "обране".
4. Бот дозволяє редагувати або вимикати трекінг.

### Додаткові можливості

- Перегляд архіву та статистики (кількість оголошень за період, тренди цін).
- Рандомний підбір оголошень за фільтрами.
- Розширена інформація на сторінці `telegraph`.
- Створення власних оголошень у боті.
- Розширені фільтри: анти-фейк, анти-рієлтор, "з тваринами / дітьми".
- Внутрішній рейтинг орендодавців.
- Аналіз описів і фото за допомогою AI.
- Партнерство з іншими джерелами (регіональні ТГ-групи тощо).

## Технічна архітектура

### 1. Збір

- Запити до джерел (API/парсинг).
- Уніфікація інтерфейсу під всі джерела (плагіни).

### 2. Трансформація

- Нормалізація даних.
- Збагачення (інформація про власника, геокодування адреси, аналіз опису).
- Створення груп дублікатів.

### 3. Загрузка

- Збереження нових оголошень в базі (вставка з оновленням).
- Створення подій (нове оголошення чи оновлення).

### 4. Матчинг

- Матчинг оголошень із фільтрами користувачів.
- Відправка події про повідомлення користувачів.

### 5. Повідомлення

- Формування повідомлення.
- Відправка через Telegram.
